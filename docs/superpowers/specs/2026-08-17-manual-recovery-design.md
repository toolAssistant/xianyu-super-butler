# 管理平台人工恢复设计

## 目标

当闲鱼风控、验证码、登录失效或连接恢复失败导致自动发货不可用时，系统通过纯文本 PushPlus 告警通知操作员。操作员到部署 Mac 后，在管理平台账号卡片点击一次“人工恢复”，即可进入 Docker 中该账号的持久浏览器完成验证。恢复成功后系统验证 Token、更新 Cookie、重启账号实例并回到 `connected`。

## 非目标

- 不在通知中发送风控 URL、控制页 URL 或 noVNC URL。
- 不公开暴露 VNC/noVNC 端口。
- 不增加自动破解滑块、远程桌面或新的第三方依赖。
- 不改变正常账号的定时 Cookie 刷新与自动发货流程。

## 操作流程

1. 系统检测到需要人工处理的风控或恢复失败，发送纯文本关键告警。
2. 操作员到部署 Mac，登录管理平台并进入账号管理。
3. 操作员点击目标账号的“人工恢复”。
4. 后端校验账号权限和运行状态，为该账号创建唯一恢复会话。
5. 后端使用内存中的最新风控 URL；若没有可用 URL，执行一次受控 Token 探测获取新的风控页面。
6. 后端在 Docker 的持久有头 Chromium 中打开风控页面并保持运行。
7. 管理平台打开本机固定 noVNC 页面，账号卡片显示恢复阶段。
8. 操作员在 noVNC 中完成滑块、扫码或其他平台验证。
9. 后端低频验证 Token；验证成功后提取并校验浏览器 Cookie，更新账号并重启实例。
10. 账号连接恢复为 `connected`，管理平台刷新状态并结束恢复会话。

## 后端设计

新增进程内人工恢复会话管理器，同一账号最多一个活动会话。会话仅保存运行所需的内存对象和非敏感状态，不向 API 返回原始风控 URL、Cookie、密码或 Playwright 对象。

新增认证接口：

- `POST /cookies/{cookie_id}/manual-recovery`：启动或返回已有恢复会话。
- `GET /cookies/{cookie_id}/manual-recovery`：查询当前恢复阶段。
- `DELETE /cookies/{cookie_id}/manual-recovery`：取消恢复并清理浏览器资源。

恢复阶段为：`starting`、`waiting_for_operator`、`validating`、`reconnecting`、`success`、`failed`、`timed_out`、`cancelled`。

普通用户只能操作自己的账号，管理员可以操作所有账号。账号连接正常且不存在人工恢复状态时，启动接口返回“当前连接正常，无需人工恢复”，不启动浏览器。重复点击返回现有会话，不创建第二个浏览器。

恢复会话默认保留 15 分钟。超时、取消、浏览器异常或 Token 验证失败不得覆盖数据库中的有效 Cookie。成功路径必须先通过真实 Token 探测，再更新 Cookie 和重启实例。

## 浏览器设计

复用现有 Playwright、`DISPLAY=:99`、`browser_data/user_{cookie_id}` 持久目录和 noVNC 服务，不增加依赖。恢复浏览器必须是有头模式，并打开该账号最新的原始风控页面。

浏览器启动失败、用户数据目录被占用、VNC 未启用或没有可用风控 URL 时，会话进入 `failed`，向管理平台返回可执行的错误说明，不重启账号。

noVNC 地址由部署配置提供，仅返回给已认证的管理平台页面。默认本机入口为：

`http://127.0.0.1:6080/vnc.html?autoconnect=true&resize=scale`

## 管理平台设计

账号卡片操作区增加带警示图标和文字的“人工恢复”按钮。

- 点击后按钮进入加载状态，防止重复提交。
- 启动成功后立即打开 noVNC，并轮询恢复状态。
- 卡片显示：启动浏览器、等待人工处理、验证 Token、重连中、已恢复或失败。
- 正常账号点击时只提示“当前连接正常，无需人工恢复”。
- 失败时显示后端返回的具体原因，并允许重新触发。
- 成功后刷新账号列表；noVNC 页面由操作员关闭。

## 告警设计

人工滑块、风控冷却、自动恢复失败、连接恢复失败和自动发货失败继续通过账号所有者启用的 PushPlus 关键告警渠道发送。

告警正文只包含：账号 ID、故障类型、简短原因、发生时间和“请到部署机管理平台点击人工恢复”。告警标题和正文均不得包含 `http://`、`https://`、`/api/captcha/control/` 或原始风控参数。

维持现有默认策略：最多尝试 3 次，同类关键告警 30 分钟冷却去重。

## 验收与测试

后端测试覆盖：

- 账号归属与管理员权限。
- 正常账号拒绝无意义恢复。
- 同一账号重复点击复用现有会话。
- 最新风控 URL 与受控探测回退。
- VNC、浏览器和持久目录启动失败。
- 15 分钟超时与显式取消。
- Token 验证失败不覆盖 Cookie。
- Token 验证成功后更新 Cookie、重启实例并返回 `success`。
- 所有关键风控告警不包含链接。

前端验证覆盖按钮加载、错误提示、状态轮询和 noVNC 打开。生产构建、Compose 展开、入口脚本测试和容器健康检查必须继续通过。
